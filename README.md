# 🍎 苹果的记账小助手

一个粉粉嫩嫩的**单文件记账工具**，帮你控制花销、存下小钱钱。双击即可在浏览器打开，无需联网、无需安装、无需服务器。

## ✨ 特点

- **零依赖**：单个 HTML 文件，内联 CSS + 原生 JavaScript，离线可用。
- **可爱风**：奶油粉配色、圆角卡片、emoji 装饰，记账也可以很治愈。
- **时刻提醒**：超支、吃喝玩乐超预算时，顶部横幅会温柔地拉你一把。
- **数据本地保存**：存在浏览器 `localStorage`，关掉再开不丢，支持导出/导入备份。

## 📋 功能清单

| 功能 | 说明 |
|------|------|
| 🏦 概览卡片 | 本月收入 / 支出 / 结余 / 可存金额，实时计算 |
| 🎯 存款目标进度条 | 目标 ¥1,000，达标变绿庆祝，超支红色警告 |
| 🍔 吃喝玩乐专项预算 | 餐饮 + 购物 + 娱乐单独设上限（默认 ¥3,500，可改），超了变红 |
| 📝 记一笔 | 金额、收入/支出切换、分类、日期、备注，可删除 |
| 🏷️ 分类管理 | 预设常用分类，可增删自定义 |
| 📊 分类支出占比 | 纯 SVG 饼图 |
| 📈 近 7 天支出 | 纯 SVG 柱状图 |
| 📅 月度切换 | 回看历史月份 |
| 💾 数据管理 | 自动保存、导出/导入 JSON、一键清空 |

## 🚀 使用

1. 下载 `记账助手.html`；
2. 双击用浏览器打开；
3. 开始记账，页面会自动保存数据。

> ⚠️ 数据保存在本机浏览器缓存中，清理缓存会丢失，请定期点击「导出备份」。

## ⚙️ 默认参数

| 参数 | 默认值 | 说明 |
|------|--------|------|
| 月工资 | ¥8,888 | 固定计入每月收入 |
| 存款目标 | ¥1,000 / 月 | 可存金额 = 结余 − 目标 |
| 吃喝玩乐预算 | ¥3,500 / 月 | 页面内可改 |
